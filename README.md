# Cozy Pal onboarding skill

This skill helps an AI assistant install Cozy Pal and Paseo, configure a coding provider and model, register a project, and guide you through pairing Cozy Deck on your iPhone.

On the Mac that runs your coding tools, give your AI assistant the [raw skill](https://raw.githubusercontent.com/NjrSea/cozy-pal-onboarding/main/SKILL.md) and ask it to help you set up Cozy Pal. To install it as a Codex skill for a project, copy [SKILL.md](SKILL.md) and the [references](references/) directory into `.agents/skills/cozy-pal-onboarding/` in that project, then invoke `$cozy-pal-onboarding`.

The [onboarding flowchart](SKILL.md#onboarding-flow) shows where to resume if Cozy Pal, Paseo, or a provider is already set up. The [troubleshooting guide](references/troubleshooting.md) covers pairing timeouts, missing projects, and which logs to check.
